# Запуск лабы

Запуск сервиса **API**
1) Прыгаем на сервер (192.168.0.204) через джампер:
```shell
ssh -J debian@37.18.14.43 debian@192.168.0.204 # 37.18.14.43 - адрес сайта , по которому он доступен в интернете
```
2) Запускаем WSGI-сервер (из сервера debian@192.168.0.204):
```shell
 /home/debian/api/run_api.sh
```
